# Security Policy

## 🛡️ Reporting a Vulnerability

Security is at the core of all operations at **Cyberdark-Security** and the **Whoami-Labs** ecosystem. If you discover a security vulnerability or security issue in any project or laboratory, we appreciate your responsible disclosure.

### 📬 How to Report
Please report vulnerabilities privately via email:
- **Email:** `contact@whoami-labs.com`

Please include:
1. Description of the vulnerability and its potential impact.
2. Step-by-step reproduction instructions or proof-of-concept (PoC).
3. Target version, system, or component affected.

### ⏱️ Response SLA
- **Acknowledgment:** Within 24-48 hours.
- **Triage & Remediation Plan:** Within 5 business days.

Thank you for helping keep the ecosystem secure!
